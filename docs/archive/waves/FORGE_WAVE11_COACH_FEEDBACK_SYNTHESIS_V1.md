## 1. Executive Summary

### If a serious S&C coach trialed FORGE today, what would they likely trust?

- **Beginner programs** across all sports. Multiple coaches independently state
  these are safe, appropriate, and well-structured for novice athletes.
- **The role bias framework** (force/velocity/conditioning emphasis profiles).
  Coaches consistently praise the system's understanding of positional demands.
- **Adaptive periodization** (the "Adj" column). Reactive week-to-week
  adjustments are recognized as sophisticated and coach-like.
- **Exposure tracking** (sprint/jump/decel/eccentric/conditioning density
  per week). This is consistently rated as an excellent feature.
- **Transparent rationale sections** ("Why This Sample Exists"). Coaches value
  understanding the "why" behind programming decisions.

### What would make them hesitate?

- **Advanced programs are indistinguishable from intermediate programs.**
  Goblet Squats for athletes with 5+ years training age. No barbell progression.
  Same exercise selection, just more sets. This is the #1 trust-breaker.
- **Programs claim role specificity but deliver generic strength work.**
  The system states "rotation emphasis: 0.8" but programs contain zero rotational
  exercises. The stated biases do not translate into exercise selection.
- **In-season programs are dangerous.** Maintaining off-season volume during
  competition phase. No match-day scheduling. 3x/week heavy strength during
  a 40-match season is inappropriate.
- **Validation flags appear but are ignored.** The system identifies volume-load
  mismatches, documents them, then delivers the flawed program anyway. Coaches
  perceive this as "the system knows it's wrong and does nothing."
- **No injury prevention protocols.** Shoulder injuries in overhead sports,
  hamstring strains in speed sports, ACL in cutting sports — none are addressed
  in program design.

### Current state verdict

**"Promising but not yet coach-trial ready for advanced athletes."**

The system is genuinely impressive for beginner-to-intermediate general athletic
development. For that population, it is arguably ahead of most automated systems.
But for advanced, in-season, or sport-specific work — the primary need of serious
S&C coaches — it has a credibility gap that must be closed before a second
external trial.

Three of eight coaches explicitly declined to trial on real athletes.
Three would trial with edits. Two would trial beginner/intermediate but not advanced.

## 4. Trust-Breaking Issues

These are the issues that would most likely cause a coach to say "I wouldn't use this":

### 4.1 "The programs describe sophisticated sport-specific requirements but deliver generic strength training."

This exact phrase — or a close variant — appears in **badminton, basketball,
and cricket** reviews. It is the single most damaging sentence in the feedback.
The system states "rotation emphasis 0.8" but programs contain no rotational
exercises. It states "high conditioning density" but half the sessions have
no conditioning. The gap between stated intent and delivered output is where
trust dies for performance coaches.

### 4.2 "Goblet Squats for advanced athletes is a clear sign the system is overly conservative and lacks advanced programming understanding."

Appears in **all 8 sports**. For a coach evaluating whether FORGE understands
high-performance S&C, seeing a Goblet Squat in an advanced program is immediate
grounds for dismissal. It signals the system was designed with a safety-first
mentality that is incompatible with performance training.

### 4.3 "The system identifies the problem but does not correct it."

Appears in **badminton, basketball, and cricket** and echoed by football/rugby.
The "Check volume load match: needs attention" warning, appearing in ~17% of
all sample programs (8/36 football, 12/48 rugby, multiple in badminton/basketball/
cricket), is a credibility killer. A coach seeing a program with a system-generated
red flag that was not acted upon will not trust the program.

### 4.4 "I would not trust these programs with any athlete beyond a complete novice."

Direct quote from **cricket** review. Badminton and basketball say functionally
the same thing. The three "format A" sports (tabular structured reviews) are
unanimous: beginner OK, everything else not yet. This is the clearest signal
that FORGE's current output ceiling is at the intermediate level.

### 4.5 "In-season programming is inappropriate — maintains off-season volumes during competition."

Appears in **all 8 sports**. For a coach managing real athletes through a
competitive season, programs that prescribe 3x/week heavy strength during a
match week are not just unhelpful — they're unsafe. This is the second most
trust-damaging issue after the Goblet Squat ceiling.

## 6. Systemic Issue Clusters

### Cluster A — Advanced Athlete Exercise Selection Ceiling

**What coaches are reacting to**: Every sport review independently flags the
Goblet Squat for advanced athletes. The exercise library peaks too early.

**Why it matters**: This is the single strongest signal that FORGE does not
understand high-performance S&C. It is the issue most likely to make a coach
dismiss the system entirely.

**Where it lives**: `exercise_library` → level-to-exercise-tier mapping.
The engine selects exercises based on a static difficulty rating and never
graduates athletes to more demanding variants.

### Cluster B — Role Specificity Depth

**What coaches are reacting to**: Bias values differ but exercise selection
doesn't. Programs feel like "general athletic development with sport labels."

**Why it matters**: The system's core value proposition is sport-specific
programming. If that's not real, the system has no reason to exist.

**Where it lives**: `role_profiles` → `exercise_selection` → `session_assembly`.
The pipeline from role bias → exercise choice → session structure is currently
decoupled. Bias values exist but don't constrain exercise selection.

### Cluster C — In-Season / Taper / Fatigue Management

**What coaches are reacting to**: Off-season volume during competition. No
match-day awareness. No volume reduction logic.

**Why it matters**: This is the most immediately practical gap. Coaches managing
athletes in season need programs that work *around* competition, not ones that
pretend the competition doesn't exist.

**Where it lives**: `periodization_engine` → seasonal context rules. The
seasonal flag is set but does not alter any programming parameters.

### Cluster D — Landing / Decel / Eccentric / Tissue Capacity Coverage

**What coaches are reacting to**: Zero eccentric exercises in some programs.
No landing mechanics training. No deceleration work for speed athletes.

**Why it matters**: This is a player welfare issue as much as a performance
issue. Absence of eccentric work in high-speed programs signals the system
doesn't understand injury risk.

**Where it lives**: `exercise_library` → missing exercise families. The
deceleration, eccentric, and landing mechanics categories are not populated
for most sports.

### Cluster E — Progression / Overload Sophistication

**What coaches are reacting to**: Same exercises across 8 weeks. No within-block
advancement. Beginner→Advanced is just more sets, not harder exercises.

**Why it matters**: Periodization requires overload. If the system can't
progress exercises within a block or across levels, it's not delivering
periodized training.

**Where it lives**: `progression_engine` → currently set/rep-only. Exercise
substitution within blocks is not supported. Level transitions change
sets/reps but not exercise complexity.

### Cluster F — Exposure Balancing and Conditioning Specificity

**What coaches are reacting to**: Conditioning is all linear shuttles. Exposure
targets (sprint: High) are not consistently met in actual programs.

**Why it matters**: Conditioning needs to match sport demands. Court sports
need multi-directional work, field sports need position-specific patterns.

**Where it lives**: `conditioning_engine` → protocol selection is metabolic-only
(MAS, RSA, intervals), not movement-pattern-aware.

### Cluster G — Sport-Specific Drill Layer

**What coaches are reacting to**: No goalkeeper dives. No scrum engagement.
No lineout jumps. No tackle prep. No rotational cricket work.

**Why it matters**: Coaches see FORGE as a general S&C system, not a
sport-specific one. Adding a sport-specific layer is the difference between
"a good system" and "my system."

**Where it lives**: No current code area → needs a new `sport_drill_library`
layer with drills per sport per role.

### Cluster H — Validation System: Diagnostic → Corrective

**What coaches are reacting to**: Red flags in ~17% of programs. System notes
them and proceeds anyway.

**Why it matters**: This undermines trust in the entire quality assurance
mechanism. A system that finds errors in its own output but does not fix them
is worse than one that doesn't check at all.

**Where it lives**: `validation` module has no correction feedback loop to
`program_builder` or `session_assembly`. It needs one.

### Cluster I — Youth / Developmental Appropriateness

**What coaches are reacting to**: Beginner programs are safe but stagnant.
Same exercises for 8 weeks. No progression narrative.

**Why it matters**: Youth development requires progressive overload even at
low absolute loads. The system's beginner track needs a clearer progression
pathway.

**Where it lives**: `progression_engine` → youth pathway doesn't advance
exercises within blocks. Fix overlaps with Cluster E.

### Cluster J — Coach Override / Editability / Output Trust

**What coaches are reacting to**: Programs are static outputs. Coaches cannot
see why decisions were made, cannot edit, and cannot compare variants.

**Why it matters**: FORGE is positioned as an assistant, not a replacement.
A coach needs to be able to modify, override, and understand the system's
choices.

**Where it lives**: New capability — output delivery layer. Currently output
is a static markdown file. Future state needs interactive editing, rationale
exploration, and variant comparison.

## 7. Coach-Trial Implications

### Must fix before the next serious external coach trial

1. **Goblet Squat ceiling** — Replace with level-appropriate barbell loading
   for advanced athletes. This is the minimum viable fix.
2. **In-season volume** — Implement basic volume reduction for competition
   phase (2x/week, 2 sets/exercise). Without this, coaches managing
   competitive athletes cannot use FORGE.
3. **Validation auto-correction** — Wire the most frequent validation flag
   ("volume load match") into the program builder so it auto-reduces volume
   instead of just emitting a warning. Without this, the validation system
   actively damages trust.
4. **Role differentiation basics** — At minimum, ensure that roles within
   a sport get materially different exercise selection. Start with the most
   egregious gap: cricket's "rotation emphasis 0.8" producing zero rotational
   exercises.

### Can wait until Wave 12+

- Sport-specific drill library (Cluster G) — high value but large build
- Conditioning movement-pattern awareness (Cluster F) — medium value, medium build
- Warm-up specificity (partial Cluster I) — medium value
- Credibility score breakdown (Cluster H cosmetic) — low value, small build
- Sport practice load integration (partial Cluster D) — high value but large build

### Already good enough for limited external testing

- Beginner programs across all sports
- Program template structure and readability
- Role bias framework (the *concept* is trusted even if the *execution* isn't)
- Adaptive periodization / Adj column logic
- Exposure tracking and density metrics
- Equipment stratification

**Recommendation**: A second coach trial should target **beginner-to-intermediate**
programs only, with fixes 1-3 above applied first. Advanced and in-season
programs should not be shown until Wave 11B or later.
